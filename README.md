# ROS 2 Manipulator Learning Workspace (arduinobot)

My workspace from Antonio Brandi's *Robotics and ROS 2 — Manipulators* course (2024): a small desktop arm ("arduinobot") with URDF, ros2_control, MoveIt 2, a task server in C++ and Python, custom messages and angle-conversion utilities. Kept as a learning record.

| Package | Content |
|---|---|
| `arduinobot_description` | URDF and display launch |
| `arduinobot_controller` | ros2_control configuration |
| `arduinobot_moveit` | MoveIt 2 configuration |
| `arduinobot_remote` | Task server (C++ and Python) driving MoveIt |
| `arduinobot_msgs`, `arduinobot_py`, `arduinobot_utils` | Interfaces and examples |

**Where this led:** [Aura mobile manipulator](https://github.com/Curious-Utkarsh/aura-mobile-manipulator) · [Franka colour sorting](https://github.com/MechaMind-Labs/franka-color-sorting-robot) · [SCARA conveyor cell](https://github.com/Curious-Utkarsh/scara-pick-and-place)
